# Shared

Código que usan **dos o más** módulos. Si solo lo usa uno, no va aquí: va a `src/modules/<ese-modulo>/`.

- `components/ui/` — Button, Modal, TextField
- `components/layout/` — AppLayout, Sidebar
- `components/icons/` — iconos
- `components/ResourceBoard.tsx` — tabla con pestañas (la usan varios módulos)
- `lib/` — cliente HTTP (`api.ts`), permisos de menú, `cn`
- `types/` — tipos compartidos (usuario, módulo, rol)
- `constants/` — constantes de navegación e imágenes
